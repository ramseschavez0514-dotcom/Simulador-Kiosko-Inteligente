# Instrucciones Generales para el IDE

Este proyecto utiliza una arquitectura multi-agente para procesar devoluciones comerciales. Siempre debes guiarte por el flujo estricto y los límites definidos en `AGENTS.md` al realizar cambios en el repositorio.

Si necesitas crear nuevos scripts o modificar lógica de negocio, asegúrate de mantener siempre el esquema de Human-in-the-Loop (HITL) para las transacciones financieras y validaciones críticas.
